# 数据来源

**正样本**:

需要覆盖：

- 不同人的体型和运动习惯；
- 合理的站距、速度、手臂姿势；
- 支持的视角和正常追踪误差；
- 仍属于目标动作的各种质量问题。

**负样本**:

| 负样本类型           | 例子                                     | 作用               |
| -------------------- | ---------------------------------------- | ------------------ |
| 常见背景动作         | 站立、走动、转身、整理衣服               | 避免未运动时乱触发 |
| 相似动作             | 弓步、单腿蹲、坐下起立、弯腰             | 学习目标动作边界   |
| 能骗过现有规则的动作 | 抬腿配合下蹲、局部角度合格但整体结构不符 | 关键类型           |

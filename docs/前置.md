## 2. PyTorch 入门：2–4 小时

### PyTorch 官方 60 分钟入门

链接：

- https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html

重点看：

- Tensor
- Autograd
- `nn.Module`
- Loss
- Optimizer
- Train loop

需要看懂这四行：

```python
logits = model(x)
loss = criterion(logits, y)
loss.backward()
optimizer.step()
```

这就是训练的核心。

## 8. 当前代码里最该先懂的五件事

| 概念             | 代码位置   | 含义           |
| ---------------- | ---------- | -------------- |
| `Dataset`        | `data.py`  | 一条样本怎么取 |
| `DataLoader`     | `train.py` | 怎么组成 batch |
| `nn.Module`      | `model.py` | 张量进、张量出 |
| `forward`        | `model.py` | 前向计算       |
| loss + optimizer | `train.py` | 参数怎么更新   |

先看懂这五个，其他细节可以后补。
